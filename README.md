# 午餐訂餐

辦公室訂便當用的小網頁。負責人選好店家、貼上 Google 地圖網址和菜單後開單，同事在座位上打開連結點餐，價格自動帶入，統計頁整理好叫餐數量和每個人該付多少。

- 網頁放 GitHub Pages
- 訂單存 Google 試算表，用 Apps Script 當後端（免費，同事不用登入）

```
index.html   網頁本體（點餐、統計、管理三個分頁）
config.js    填入後端網址
logic.js     共用邏輯，網頁和 Apps Script 都用這一份
apps-script/Code.gs   後端程式，貼進 Apps Script
```

## 先試用

`config.js` 的 `API_URL` 留空時是示範模式，直接用瀏覽器打開 `index.html` 就能操作，資料只存在自己的瀏覽器。

## 設定步驟（約 15 分鐘）

### 1. 建立試算表和後端

1. 開一份新的 Google 試算表，名稱隨意（例如「午餐訂餐」）。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把編輯器預設的 `程式碼.gs`（英文介面叫 `Code.gs`）內容全部換成本專案的 `apps-script/Code.gs`。
4. 左側「檔案」旁的「＋」→「指令碼」，命名為 `Logic`，貼上 `logic.js` 的全部內容。
5. 上方函式選單選 `setup`，按「執行」。第一次會要求授權：選自己的帳號 →「進階」→「前往（不安全）」→「允許」。這是自己寫的程式，Google 沒審核過才會這樣提示。
6. 回到試算表，應該多了「店家」「菜單」「開單」「訂單」四個工作表。
7. （建議）設定管理密碼：Apps Script 左側齒輪「專案設定」→ 最下方「指令碼屬性」→「新增指令碼屬性」，屬性填 `ADMIN_PIN`，值填一組數字。沒設定的話，任何人都能開單、改菜單、標記付款。
8. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
   - 按「部署」，複製「網頁應用程式」網址（結尾是 `/exec`）。

### 2. 放上 GitHub Pages

1. 在 GitHub 新增一個 repository（免費方案需設為 Public）。
2. 上傳 `index.html`、`config.js`、`logic.js`。
3. 編輯 `config.js`，把剛才的 `/exec` 網址貼進 `API_URL` 的引號裡，存檔。
4. repository 的「Settings」→「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按「Save」。
5. 等一兩分鐘，網址會是 `https://你的帳號.github.io/repository名稱/`。

## 每天怎麼用

**負責人**

1. 「管理」→「新增店家」：貼上 Google 地圖網址會自動帶出店名；菜單每行一項，品名後面接價格。同一家店之後直接沿用，不用重建。
2. 選店家、設定截止時間 →「開單」。
3. 按「複製點餐網址」貼到群組。
4. 截止後到「統計」→「複製叫餐內容」，直接貼給店家或照著唸。
5. 收錢時在收款清單按「未付」，會蓋上「已付」。

**同事**

填名字、按 ＋ 選餐點、需要的話寫備註，按「送出點單」。截止前重新送出就會更新，名字會記在瀏覽器裡，下次不用再填。

## 注意

- **Google 地圖網址讀不到菜單**：Google 沒有開放店家菜單資料，所以菜單要自己貼一次。來源可以是外送平台的店家頁面（直接複製文字），或用手機 Google Lens 拍菜單後「複製文字」。「排骨飯……$90元」「雞腿飯　１１０」這類寫法都讀得懂，沒有價格的行（像分類標題）會自動略過。
- **短網址**：從手機分享的 `maps.app.goo.gl/...` 由後端展開後讀店名；示範模式讀不了，手動填就好。
- **價格以點餐當下為準**：每筆訂單會記下當時的單價，之後改菜單不會影響已送出的點單。
- **改了 Code.gs 或 Logic.gs 要重新部署**：「部署」→「管理部署作業」→ 鉛筆圖示 →「版本」選「新版本」→「部署」。網址不會變。`logic.js` 和 `Logic.gs` 要保持同一份內容。
- **公司 Google 帳號可能不允許「所有人」存取**：遇到這種情況，改用個人 Gmail 建試算表。
- **安全性**：GitHub 上的網址公開可見，點餐不需要登入、靠名字辨識，適合辦公室內部使用。開單、改菜單、標記付款靠 `ADMIN_PIN` 保護。
- **對帳**：所有訂單都留在試算表「訂單」工作表，有日期、店家、單價、數量、付款欄，月底可以直接篩選或做樞紐分析。
